# CBI process contract

CBI accepts 15-minute observed speed data and a frozen canonical TMC/link mapping. The CLI adapter translates configured source columns into the internal schema. Internal numbered folders and their fields are producer contracts consumed by congestion-boundary mapping and downstream corridor measurement.

No input path is computed from a repository location, environment-specific username, dated directory, or “latest” pointer. Output roots are either explicit or derived next to the primary input. Existing output is never silently overwritten.

The boundary producer precedence is direct observation, spatial treatment, then either Ridge ML or VDF class. A direct matched TMC with no observed candidate congestion remains protected from downstream boundary imputation.
